# XML and JSON Validation Course

A complete classroom-ready guide for learning **XML**, **XML Validation**, **XPath**, **XSLT**, **JSON**, and **CORS**, prepared according to the official course book.

This course takes students from the fundamentals of XML and well-formed documents to practical validation with DTDs and Schemas, transformation with XSLT, and modern data exchange using JSON.

---

## About This Course

- Built with **React** + **Docusaurus**
- Hosted on **GitHub Pages**
- Content is based on the official book
- Every session ends with:
  1. **Summary**
  2. **Test Your Knowledge**
  3. **Try It Yourself**

---

## Course Structure

The course contains **8 sessions**. Each session is designed for approximately **2 hours**.

| Session | Title |
|---------|-------|
| 01 | XML and XML Validations |
| 02 | XML Parser and DOM |
| 03 | XPath |
| 04 | XSLT |
| 05 | JSON |
| 06 | Working with JSON |
| 07 | Advanced JSON Features |
| 08 | CORS |

---

## Student Expectations

Students are expected to:

1. Read the lesson material carefully.
2. Type and execute the examples themselves.
3. Complete the **Try It Yourself** exercises.
4. Attempt the **Test Your Knowledge** questions.
5. Practice outside the classroom.
